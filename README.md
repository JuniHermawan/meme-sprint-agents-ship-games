A three-panel meme comic about AI agents building games and apps, drawn entirely in pure-stdlib Python: a user asks an agent for a fun game, the agent ships 12 games in 0.4 seconds, and the punchline lands — fun was not in the prompt.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, deterministic — the same bytes on every run). No third-party packages, no network, no files outside this repository.
